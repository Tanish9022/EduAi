# EduAI Assist

AI-powered Admission Assistant SaaS for colleges and educational institutions.

EduAI Assist automates admission-related student support using AI chatbots integrated with WhatsApp, websites, and dashboards.

---

# Features

- AI Admission Chatbot
- WhatsApp Integration
- AI Document Understanding
- Admission Analytics
- Multi-tenant SaaS
- Real-time Dashboard
- Student Query Monitoring
- Multi-language Support

---

# Tech Stack

Frontend:
- Next.js
- Tailwind CSS

Backend:
- FastAPI

Database:
- PostgreSQL

AI:
- Gemini/OpenAI APIs
- LangChain
- RAG Pipeline

- ChromaDB/Pinecone
